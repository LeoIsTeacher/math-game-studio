# Math Game Studio

为 Leo 和小学数学教师设计的可复用 Codex Skill，引导开发可在浏览器运行的 HTML 数学小游戏。

通过“主控对话 + 专项对话”推进项目：主控维护 `PROJECT.md`，在恰当阶段提示新开专项对话并提供完整首条消息；专项交付成果和“回传主控”摘要，主控验收后再安排下一步。

## 安装与开始

将本仓库下载并解压，把包含 `SKILL.md`、`agents/`、`assets/` 和 `references/` 的目录命名为 `math-game-studio`，放入个人 Codex 技能目录 `$CODEX_HOME/skills/`；未设置 `CODEX_HOME` 时使用 `~/.codex/skills/`。

在能够识别该 Skill 的新对话中输入：

```text
使用 $math-game-studio，作为主控引导我开发一个新的小学数学 HTML 小游戏。
先明确教学目标和核心玩法，在恰当阶段提示我新开专项对话，并给出可直接复制的首条消息。
```

继续已有游戏时，提供该游戏最新的 `PROJECT.md` 及需要的资源文件。

## 六类专项

- 教学与玩法：将教学目标转化为可观察的数学行为和核心循环。
- 游戏开发：低成本原型、素材接入、修复和正式交付。
- 美术与角色：先形成角色设定，再生产一致的角色状态与素材。
- 动画：角色优先序列帧，环境效果优先 CSS/JS。
- 音乐与音效：分析参考的抽象特征，重新原创音乐与声音。
- 测试与迭代：教师试玩、真实学生行为观察和针对性修复。

每次交接都会生成类似以下提示，并附完整任务书和回传格式：

> 现在，你重新开一个对话，向他发送以下内容，开始你的音乐与音效设计：……

## 九条原则

1. 先做完整角色设定，再拆素材。
2. 从参考音乐的抽象特征出发重新原创。
3. 专业素材优先交给专业工具。
4. 一个游戏一个独立项目，由主控协调专项对话。
5. 先验证低成本核心玩法原型，再制作正式美术。
6. 用 LOCKED / EXPLORING 管理已确认需求和探索内容。
7. 从 v0.1 到 v1.0 保留稳定版本和恢复点。
8. 将真实学生试玩纳入开发，记录行为证据。
9. 经过多款游戏验证后逐步沉淀 TeacherLeo Math Game Kit。

## 文件结构

```text
SKILL.md                              主控工作流
agents/openai.yaml                    名称与默认调用提示
assets/PROJECT.template.md            单款游戏的事实文件模板
assets/RETURN.template.md             专项回传模板
references/specialist-prompts.md       六类专项首条消息模板
references/acceptance-and-versioning.md 验收、版本和组件沉淀规则
```

Skill 保存制作方法；每款游戏自己的 `PROJECT.md` 保存项目事实。专项提示词需由主控结合实际事实填写，无需用户手工拼接模板。

## 使用边界

这是制作流程 Skill，不包含现成游戏引擎，也不自带图像或音频生成服务。专业工具不可用时会输出制作规格，并将实际素材标记为待制作。

当前版本为 1.0.0。结构与模板引用已检查；完整教学效果和工作流适用性仍需在实际游戏项目及课堂试玩中持续验证。
